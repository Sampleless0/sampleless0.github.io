Wordle Solver

Automatically solves Wordle puzzles.

Utilising a constraint-based Wordle algorithm with a maximum distinct-feedback heuristic to minimise the number of guesses.

Python

Open Github Repository
> about.load()

The Problem

There is a lot of 5-letter words, roughly 13000. What is the best way to reduce that number to 1 with as few guesses as possible.

The Solution

By choosing a word based on maximising the number of words it can remove based on the Wordle result, it will maximise the number of words removed per guess.

> process.show()

Data

By having all the words available in a dataset, the best option can be filtered much easier.

Select Best Word

By determining the number of distinct paths each word can filter to, the algorithm chooses the result with the word that branches to the most paths.

Filter

Filter the options based on Wordle results, however all words are still considered when used as a filter for the next run.

Implementation

While primitive, it allows for fast lookups to the colour of the tiles while increases speed.
